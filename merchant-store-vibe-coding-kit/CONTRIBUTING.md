# Contributing

Contributions are welcome through the Ping Business repository.

By intentionally submitting a contribution to this directory, you agree that
your contribution is provided under the Apache License, Version 2.0, unless a
separate written agreement explicitly states otherwise.

Before opening a pull request:

1. Read `AGENTS.md` and preserve the documented security boundaries.
2. Do not commit credentials, API keys, customer data, generated `.env` files,
   Terraform state, or platform tokens.
3. Run `./scripts/validate.sh` from this directory.
4. Explain behavior changes and include tests or validation evidence.
5. Do not add assets unless their redistribution rights are documented.
